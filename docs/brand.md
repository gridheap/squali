# Squali identity

The wordmark is **squa.li**, with the dot immediately before `li`. The evergreen emblem contains five sharks circling in one direction: independent agents sharing a common direction. It uses the existing application palette, sharp fins and clear negative space.

Asset: [`public/squali-five-sharks.png`](../public/squali-five-sharks.png), transparent PNG, 550,462 bytes. Navigation reserves 48 × 48 px on desktop and 36 × 36 px on mobile. The wordmark remains accessible HTML using the application's existing Adobe Proxima Nova loader; the emblem is decorative within the named home link. The favicon reuses the same asset.

Generated using the built-in image generation tool. No CLI fallback or separate image API was used. The original transparent output was copied without raster editing.

## Final prompt

Create a standalone transparent logo emblem for Squali, a source control product for parallel coding agents. Exactly five separate sharks, each with a distinct head, sharp fins and forked tail, viewed from above. Lean, angular, forceful silhouettes in a compact clockwise hunting formation. Preserve clear negative space between every shark and a small open center. One deep evergreen color, #155747, matching the existing product. The mark should fill roughly 88% of a square canvas. No letters, wordmark, gradients, shadows, water, border or background. A clear transparent alpha channel.
